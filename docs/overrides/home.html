MOSE-GPU

MOSE on NVIDIA GPUs

The GPU port of MOSE, the open-source compressible-flow solver of the Hydra suite: the same equations, numerics and input files, every kernel on the device, one GPU per MPI rank, and the same results as MOSE on its test cases.

MOSE, on the device

The physics and numerics of MOSE, with every kernel running on the GPU

Compressible Flow Solver

Euler and Navier-Stokes equations on multi-block structured grids, steady and time-accurate, from the same input files as MOSE.

High-Order Numerics

Every Riemann solver, limiter, shock sensor and integration variable set of MOSE — HLL, AUSM, SLAU and Roe families, low-Mach preconditioning.

Finite-Rate Chemistry

Multi-species reacting flows with stiff RADAU5 or RODAS integration of every cell on the device.

Turbulence Modelling

RANS: Spalart-Allmaras (with R, RC and compressibility corrections), Menter SST and SST-RC, Wilcox k-ω 2006.

Multi-GPU Execution

One GPU per MPI rank, with the halo exchange on the device and CUDA-aware MPI.

Flexible I/O

Tecplot (ASCII & binary) and VTK output. Point probes for time histories and full restart capability.

Up and running in minutes

The mose launcher reads a case, builds the matching binary once and submits the run: species count and turbulence model come from the case itself.
